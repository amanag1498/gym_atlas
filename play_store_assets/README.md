# Atlas Google Play release assets

This folder contains the checked-in, non-secret assets and listing copy for the
Gym Atlas and Gym Atlas Coach releases.

## Ready assets

- `branding/atlas-master-icon.png`: current silver Gym Atlas icon source.
- `branding/atlas-play-store-icon.png`: 512 x 512 Play Store icon.
- `member/feature-graphic-1024x500.png`: member feature graphic.
- `trainer/feature-graphic-1024x500.png`: trainer feature graphic.
- `member/listing.md` and `trainer/listing.md`: store names, descriptions,
  keywords, URLs, and reviewer notes.
- `member/play-console-fields.md` and `trainer/play-console-fields.md`: exact
  ready-to-paste Play Console values.
- `member/screenshots/` and `trainer/screenshots/`: older promotional visuals
  at 1080 x 1920 that still show the blue `A` mark; refresh them before use.
- `member/screenshots-real-ui/` and `trainer/screenshots-real-ui/`: production
  widget captures that can be used while the promotional visuals are refreshed.
- `app-content-answers.md`: target audience, app access, rating, health and
  declaration answers.
- `final-upload-runbook.md`: ordered submission, testing and rollout steps.
- `build-artifacts.md`: final AAB locations, checksums and upload-certificate
  fingerprints.
- `release-checklist.md`: final Play Console and build checklist.
- `data-safety.md`: declaration worksheet based on the current app behavior.

The launcher icon has also been installed into every Android density bucket in
both Flutter apps, including adaptive icon resources.

## Image-generation provenance

The icon and both feature graphics are generated by
`scripts/generate_store_brand_assets.sh` from the same silver Gym Atlas mark
used by the Member and Trainer app icons. The original blue `A` graphics have
been replaced. The source files are retained for regenerating store sizes.
The matching 1024 x 1024 iOS reference icon is in
`app_store_assets/branding/gym-atlas-app-icon-1024.png`; the iOS icon shipped
to users is embedded in each app's `AppIcon.appiconset` and uploaded in its IPA.

## Screenshot provenance

The eight older promotional visuals were generated with the built-in image
generation workflow from the previous blue `A` mark and verified app
functionality. They use illustrative app-style cards without device frames.
Do not upload them alongside the new `G` artwork until their branding is updated.
